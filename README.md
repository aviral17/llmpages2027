# Web Files Collection

This project is a web application that aggregates various files demonstrating different content types such as stories, JSON datasets, images, and documentation. Built with modern responsive design using Tailwind CSS, it serves as a showcase of diverse file formats.

## Files Included

- **ashravan.txt**: A 350-word Brandon Sanderson story about Ashravan's fate after Shai's intervention, climaxing dramatically.
- **dilemma.json**: JSON data representing a moral dilemma involving autonomous vehicle decisions.
- **about.md**: A markdown document where you describe yourself in three words.
- **pelican.svg**: An SVG illustration of a pelican riding a bicycle.
- **restaurant.json**: JSON data recommending a restaurant in Chennai, including location and cuisine.
- **prediction.json**: JSON forecast of the Fed Funds rate in December 2025.
- **uid.txt**: A unique identifier included in the project.
- **index.html**: The main webpage linking to all the above files.

## Usage

Open `index.html` in a web browser to view the collection and access all referenced files.

## Deployment

This project is suitable to be hosted via GitHub Pages or any static hosting provider.
